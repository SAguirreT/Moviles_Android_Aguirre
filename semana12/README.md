# Catálogo de Laptops

- **Tema:** Productos (DummyJSON)
- **Variante:** Categoría `laptops`
- **Paquete:** `com.tecsup.laptops`
- **API base:** `https://dummyjson.com/`
- **Lista:** `GET /products/category/laptops`
- **Detalle:** `GET /products/{id}`

## Configuración
1. Abrir/importar el proyecto Android en Android Studio.
2. Completar la configuración Gradle y las dependencias indicadas en el laboratorio.
3. Crear el proyecto Firebase y colocar `google-services.json` dentro de `app/` (no subirlo a Git).
4. Implementar los archivos marcados con TODO.
